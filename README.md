# Evolving Mobs (Forge 1.20.1)

## Сборка
1. Нужна Java 17.
2. Скопируй в папку проекта `gradlew`, `gradlew.bat` и папку `gradle/` из официального Forge MDK 1.20.1
   (https://files.minecraftforge.net -> 1.20.1 -> Mdk).
3. `./gradlew build` -> готовый мод в `build/libs/evolvingmobs-1.0.0.jar` -> кидай в папку mods.
   Для запуска из IDE: `./gradlew genIntellijRuns` (или genEclipseRuns), затем runClient.

## Стадии (по дням мира, настраивается в config/evolvingmobs-common.toml)
- 0 Обычные (дни 0-4)
- 1 Закалённые (с 5-го дня): HP +50%, урон +25%, открывают двери, подбирают лут
- 2 Мутанты (с 15-го): HP x2.5, урон x1.75, быстрее, ломают двери, ставят блоки (мосты/столбы),
  не горят на солнце, зовут стаю при ранении, крупнее
- 3 Выродки (с 30-го): HP x5, урон x3, +20% скорость, ломают блоки, регенерация, огромные и
  кривые, с душевым огнём, красное имя, больше опыта и шанс алмаза

Дополнительно: убийца игрока эволюционирует; 10% мобов спавнятся сразу на стадию выше.
Команда (оп): /mobevo force <-1..3>  (-1 = авто)
